Large-scale online gaming data processing and visualization

A resource-conscious project to generate gaming events, stream and process them with Kafka, store results in SQLite, and build an interactive analytics dashboard. Performance claims will be reported only after measured experiments.

How to start the dashboard View source on GitHub Setup and commands
The live analytics dashboard runs locally, not on this website.

Use the startup guide below to run Kafka, the API, consumer, and dashboard on your laptop. GitHub Pages cannot start those services or display their live data by itself.

Start the live dashboard on Windows

These steps run the real local pipeline. Keep each service open in its own PowerShell window. The dashboard link uses your own laptop, so it works only from that laptop while the services are running.

Before starting the full pipeline, make sure at least 2 GB of RAM is free. This project has not been tested with the Kafka broker, API, consumer, and dashboard running together on a laptop with less free memory.

1. Open PowerShell in the project folder and install Python dependencies

Use the folder containing this project's README.md.

py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

2. Download Kafka and prepare its KRaft storage (first time only)

This uses Kafka 4.4.0, Java 17 or newer, and a user-writable tools directory. Run this once from the project folder. Do not format storage again after it has been initialized. 

$version = '4.4.0'
          $project = (Get-Location).Path
          $tools = Join-Path $HOME 'tools'
          $kafkaHome = Join-Path $tools "kafka_2.13-$version"
          $archive = Join-Path $env:TEMP "kafka_2.13-$version.tgz"
          New-Item -ItemType Directory -Force $tools | Out-Null
          Invoke-WebRequest "https://downloads.apache.org/kafka/$version/kafka_2.13-$version.tgz" -OutFile $archive
          tar -xzf $archive -C $tools
          Copy-Item (Join-Path $project 'kafka\server.properties') (Join-Path $kafkaHome 'config\server.properties') -Force
          $env:KAFKA_HEAP_OPTS = '-Xms256m -Xmx512m'
          $storage = Join-Path $kafkaHome 'bin\windows\kafka-storage.bat'
          $config = Join-Path $kafkaHome 'config\server.properties'
          Set-Location $kafkaHome
          $clusterId = & $storage random-uuid
          & $storage format -t $clusterId -c $config

3. Start the Kafka broker (PowerShell window 1)

$kafkaHome = Join-Path $HOME 'tools\kafka_2.13-4.4.0'
$env:KAFKA_HEAP_OPTS = '-Xms256m -Xmx512m'
Set-Location $kafkaHome
.\bin\windows\kafka-server-start.bat .\config\server.properties

4. Start the consumer (PowerShell window 2)

Open this window in the project folder.

.\.venv\Scripts\python.exe -m kafka.consumer

5. Start the API (PowerShell window 3)

.\.venv\Scripts\python.exe -m uvicorn backend.app:app --host 127.0.0.1 --port 8000

6. Start the dashboard (PowerShell window 4)

.\.venv\Scripts\python.exe -m streamlit run dashboard/app.py

Open http://localhost:8501 on the same laptop.

7. Generate a continuous stream of Kafka events (PowerShell window 5)

.\.venv\Scripts\python.exe -m kafka.producer --count 0 --rate 5 --players 50 --seed 42

Stop each process with Ctrl+C. The dashboard refreshes every five seconds from the API and SQLite data written by the consumer.
